Multiples (Triple/Quadruple) — nouvelle coche « Avec retenue » (cochée par défaut : les réglages existants ne changent pas) ; décochée, seuls des N sans retenue sont proposés, avec la convention des multiplications (chaque chiffre sauf le plus à gauche multiplié par le facteur reste < 10 : triple de 7 = 21 est sans retenue, triple de 47 en a une) ; garde d'erreur si aucun multiple n'est possible avec ces réglages.
