# Calcul mental — v278

- Conseil étoile dans les stats Défi : à partir du 5e défi d'un palier, quand les 3 derniers défis sont tous à 30 bonnes réponses ou plus, une carte indique l'opération la plus ratée et son type d'erreur dominant (retenue, table voisine, inversion de chiffres…). Le conseil est collant et ne disparaît qu'au changement de palier. Bouton « S'entraîner (5 questions) » : entraînement ciblé sur cette opération, aux réglages du palier, qui reprend les 5 dernières erreurs de l'enfant (y compris ratées au 1er essai puis réussies au 2e) puis complète aléatoirement.
